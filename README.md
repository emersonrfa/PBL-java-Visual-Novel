# PBL - Java Visual Novel
> A Java-based Visual Novel engine developed for the **Problem-Based Learning (PBL)** methodology at Universidade Estadual de Feira de Santana (UEFS).

---

## 📌 About the Project

This repository hosts the development of a Visual Novel game created as part of the **Algorithms and Programming II** course in the third semester of the **Computer Engineering** program at **Universidade Estadual de Feira de Santana (UEFS)**.

---

## 💡 What is PBL?

**PBL** stands for **Problem-Based Learning**. It is an instructional student-centered approach where learning is driven by solving realistic, complex, and open-ended problems. 

Rather than focusing solely on traditional lectures, students work in teams to analyze challenges, design architectural solutions, apply programming practices, and deliver fully functional projects. In this context, building a Visual Novel engine serves as a practical domain to master advanced programming techniques and object-oriented design in Java.
